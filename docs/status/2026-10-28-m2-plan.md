# Plan: M2 Data and sync, 2026-10-28

M2 scope (AGENTS.md section 11): schema, migrations, RLS with tests, auth, API gateway with OpenAPI contract and version enforcement, household and invites, Drift database, outbox and sync engine, live updates over WebSocket.

**Exit:** two devices share plants and waterings, including offline then reconnect. Android only (ADR-0009), so two Android devices, or a phone and the emulator.

## Prerequisites to start in parallel (product owner)

1. **Three Supabase projects** (`dev`, `staging`, `prod`). In each, use the **asymmetric JWT signing keys** (ECC/RSA, not the legacy shared secret): the Worker verifies tokens through JWKS (ADR-0012). Needed by 2.4; local work runs on the Supabase CLI stack until then.
2. **Google sign-in:** a Google Cloud project with an OAuth "Web" client (for Supabase) and an "Android" client for `pl.pampait.plantnfc` with the debug key's SHA-1. Needed by 2.8.
3. **Email magic links in production** need an SMTP provider in Supabase (the built-in sender is rate-limited). Needed before real users, not for testing.
4. **Cloudflare:** check that Durable Objects and Hyperdrive are available on your plan. Needed by 2.4 and 2.7.
